# Private friend pilot

The repository must remain **private** until the owner explicitly approves a public release. Do not promote the project, change the portfolio or contact anyone automatically. The owner can invite friends deliberately after reviewing this release.

## Suggested pilot

Start with 3–5 volunteers with varied creative backgrounds and AI familiarity. Include at least one typed-only user, one person with multiple roles at a company, and one freelancer or career changer. Give them the README and platform guide. Explain the privacy notice and that feedback must be redacted or synthetic. Sharing a private repository or ZIP does not make uploaded personal information private from an AI provider.

Each volunteer should try:

1. Begin using an existing resume or a project description. Check that goals come first and questions feel manageable.
2. Explore the last three companies (or all if fewer); pause or defer at least one area. Notice whether quieter contributions emerge and whether answered questions repeat.
3. Review the proposed assessment and accomplishment claims. Correct one detail before approving outputs.
4. Produce a resume and relevant case study, then a presentation outline from the same evidence. Check attribution and unsupported claims.
5. Save a full record, open a fresh conversation or different assistant, import it and resume. Check mode preference, fuller notes and unfinished questions survive.
6. Change the goal or add a forgotten project. Confirm proposed cross-material updates are shown for review.

A participant can stop at any time. Never request sensitive employer documents to complete a test.

## Lightweight feedback form

- App/model/date, if known:
- Goal and creative discipline, broadly:
- Where did setup or a question become confusing?
- Did you discover a contribution you had overlooked? Describe generically.
- Any invented claim, wrong ownership, repeated question or missing export state?
- Did the record restore in a new conversation? What was missing?
- Was typing/voice respected? Any repeated voice suggestion?
- Which output was useful, and what still needed editing?
- Redacted or synthetic reproduction only:

## Gate before public release

Owner reviews setup success on both Claude and ChatGPT, record migration, coverage and claim accuracy. Resolve every invented metric/ownership, private-data transmission or lost-approval defect before broader use. Document remaining usability issues and actual tested app/model/date; do not turn this small pilot into claims of proven effectiveness.

After approval, prepare an anonymized/synthetic example of a real improvement with the participant's separate consent if their words are used. Then plan selective sharing with creative communities and a portfolio link. Outreach, public release and portfolio edits require a later instruction; none are part of this pilot build.
