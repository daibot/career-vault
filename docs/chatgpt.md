# Use Career Vault with ChatGPT

Checked against official documentation on October 29, 2026. Interfaces, account access and workspace settings can change.

## Simplest path

1. Start a new conversation in ChatGPT.
2. Upload the complete `career-vault-playbook.txt` release file if attachments are supported, or paste its contents. Then send the starter message in the README. Ask ChatGPT to confirm it can read the complete playbook.
3. Answer the first goal question. Choose typing or an available voice option. You can add existing materials after the opening.
4. Before stopping, ask for the full Markdown checkpoint and save it in a private location you choose. Confirm a downloaded or copied file actually exists and contains the full record.

ChatGPT supports attaching documents and other files; exact support depends on the environment. A project can keep related files and instructions together, but you still need your own export for portability. These are documented in [Use ChatGPT](https://learn.chatgpt.com/docs/use-chatgpt). Project setup is optional: provide the playbook and record, and explicitly ask the assistant to follow the playbook.

## If you prefer speaking

In the ChatGPT desktop app, where available, choose **Start voice chat** in a conversation or **Start new voice chat** for a new one. Allow microphone access when prompted. You can speak answers and later return to typing. Availability depends on account, rollout and workspace settings. See [ChatGPT Voice](https://learn.chatgpt.com/docs/features/voice) for the current controls and supported surfaces. If your app differs, use its current official guidance; typing or system dictation is a practical fallback. Career Vault itself cannot switch voice on.

Do not assume voice has read an attachment: ask it to state which record/version it can access. If unavailable, return to text and provide the missing content. Review names, dates and numbers that speech recognition may have misheard.

## Resume or move elsewhere

Provide the same playbook plus your latest private career record. Say: “Resume Career Vault from this record. Keep my preferences and approved claims. Confirm the goal and ask the next unanswered question.” If context is missing, supply it instead of relying on memory.

The `.zip` is an Agent Skills package for hosts supporting that format; this guide uses text/upload and makes no claim that uploading a ZIP or opening GitHub installs a skill in ordinary ChatGPT chat. Career Vault does not require a special paid integration or separate account with its creator; provider features may have their own access requirements.
