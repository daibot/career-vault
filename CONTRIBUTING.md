# Contributing

This is currently a private pilot. Keep access and visibility private until the owner approves release.

Use synthetic examples only. Do not submit personal career records, client material, credentials or unredacted transcripts. Report behavior with the smallest synthetic reproduction, host/model/date if known, expected result and actual result.

Preserve one canonical playbook in `skill/career-vault/`. Keep platform claims in the onboarding guides and cite current official documentation. Changes should improve observed behavior, not just add rules. Run the validation command in `docs/release.md`, inspect the generated bundle, and rerun relevant scenarios. Clearly distinguish simulations from live host testing.

For a change affecting attribution, approvals, exports, privacy or three-company coverage, add a behavioral scenario and preserve the actual response with a reviewer assessment. Do not infer that a keyword check proves model compliance.
