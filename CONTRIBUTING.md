# Contributing

Career Vault is a public beta AI skill. Feedback and contributions are welcome. [Report beta feedback](https://github.com/daibot/career-vault/issues/new?template=feedback.md) with a small synthetic reproduction.

**Issues and pull requests are public.** Do not submit personal career records, client material, credentials or unredacted transcripts. Include host/model/date if known, expected behavior and actual behavior. Never submit private information merely to prove a bug.

Preserve one canonical skill in `skill/career-vault/`. Keep platform claims in the onboarding guides and cite current official documentation. Improve observed behavior rather than accumulating rules. Run `python3 scripts/release.py`, inspect the generated bundle and rerun relevant scenarios. Distinguish simulations from actual live host tests.

For changes affecting attribution, approvals, exports, privacy or three-company coverage, add a behavioral scenario and preserve the actual response with a reviewer assessment. A keyword check does not prove model compliance. Keep examples synthetic and labeled.
